# Support

- Usage is described in the [README](README.md) ([на русском](README.RU.md)),
  the API reference is on [JSR](https://jsr.io/@arelive/ffpr/doc).
- Changes between versions, breaking ones included,
  are listed in the [changelog](CHANGELOG.md).
- Bugs and feature requests go to
  [issues](https://github.com/arebaka/ffpr/issues).
- Questions and ideas go to
  [discussions](https://github.com/arebaka/ffpr/discussions)
  or to [@arelive](https://t.me/arelive) on Telegram.
- Vulnerabilities are reported privately, see [SECURITY.md](SECURITY.md).

## Bug reports

A bug report should include:

- the game and the platform: Switch, PC or PlayStation;
- the ffpr version and the runtime with its version: Node.js, Bun or Deno;
- the code that fails and the full error message;
- the save file, if the problem shows up only with it.
